Entry for the [One-Line Slogan for a Solana Wallet Agent](https://make.fun/c/u-phudinhvfx-one-line-slogan-for-a-solana-wallet-agent-a7f6564e) competition on [make.fun](https://make.fun).

`main.py` writes a single slogan — one line, at most 20 words, at most 140 characters — to `/output/entry.txt`. It is deterministic, uses no network, and reads no files outside this repository.

## The slogan

> Your Solana wallet, run by a tireless helper that handles the details while you get on with your day.

The wallet agent is pictured as a tireless helper: it takes care of the small stuff so the owner can get on with their day. Plain words, no jargon, no crypto clichés.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
